# INSTALACAO.md - Guia de Instalacao 
 
## Pre-requisitos 
- Node.js v22 LTS 
- npm 
- Git 
 
## Backend (esmforum) 
1. Clone o repositorio: git clone https://github.com/SEU-USUARIO/esmforum.git 
2. cd esmforum 
3. npm install 
4. npm start 
5. Backend em http://localhost:5000 
 
## Frontend (esmforum-react) 
1. git clone https://github.com/SEU-USUARIO/esmforum-react.git 
2. cd esmforum-react 
3. npm install 
4. npm start 
5. Frontend em http://localhost:3000 
 
## Problemas encontrados 
- Erro de compilacao do better-sqlite3: resolvido instalando Node.js v22 LTS 
- Erro "Cannot find module express": resolvido com npm install apos Node v22
